# KKN Hub - Portal Otomasi Surat, Email, Link & Jadwal KKN

Aplikasi web mandiri (*standalone*) berbasis **HTML5, CSS3, dan JavaScript murni** yang dirancang untuk mempermudah administrasi kegiatan mahasiswa Kuliah Kerja Nyata (KKN).

## 🚀 Cara Menjalankan

Aplikasi ini **tidak memerlukan instalasi server atau dependensi apa pun** (tanpa Node.js, npm, atau database eksternal).

1. Buka folder ini di File Explorer laptop Anda.
2. **Klik ganda berkas `index.html`** untuk langsung membukanya di browser (Google Chrome, Microsoft Edge, Mozilla Firefox, dll.).
3. Anda juga dapat menyalin 3 berkas (`index.html`, `style.css`, `app.js`) ke flashdisk atau mengirimkannya ke rekan tim KKN Anda.

---

## 📋 Fitur Utama

1. **Generator Surat Resmi KKN (Word & PDF)**:
   - Template surat: Undangan Lokakarya, Izin Tempat/Balai, Permohonan Narasumber, Pemberitahuan Proker, dan Ucapan Terima Kasih.
   - *Live preview* kertas surat A4 dengan Kop Surat berstandar resmi, nomor surat, dan kolom tanda tangan Ketua & Sekretaris KKN.
   - Ekspor langsung ke berkas **Microsoft Word (.doc)** dan **download PDF** tanpa membuka dialog cetak.
   - Identitas visual menggunakan logo Mandeh dan palet Clouds, Clear Skies, Deep Ocean, Blueberry, Bluebird, serta aksen Sun/Sunset.

2. **Otomasi Email & Broadcast**:
   - Template pesan dengan variabel dinamis otomatis (`{nama}`, `{kegiatan}`, `{tanggal}`, `{lokasi}`, `{kelompok}`, `{desa}`).
   - Opsi sekali klik: **Kirim via Gmail Web**, **Kirim via Email Client**, **Broadcast via WhatsApp Web**, dan **Salin Teks**.

3. **Direktori Link Penting**:
   - Penyimpanan link Google Drive, SIM KKN LPPM, Google Form presensi, dan kontak darurat desa.
   - Filter kategori, pencarian cepat (*search*), dan pin favorit.

4. **Jadwal & Timeline Kegiatan**:
   - Manajemen agenda proker, deadline LPPM, dan jadwal piket harian.
   - Penanda prioritas (Tinggi, Sedang, Rendah) serta status kegiatan interaktif.

5. **Pengaturan Identitas KKN**:
   - Pengaturan nama kampus, kelompok KKN, desa penempatan, DPL, ketua, dan sekretaris tersimpan aman di *Local Storage* peramban.
